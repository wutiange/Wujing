10:T3a0e,<p>App 走账号密码登录。它不是用户每天都打开的主流产品，账号密码往往记不住、也不愿意再记一份。接入系统自动填充后，注册或登录成功时把凭证交给系统密码管理；下次打开直接一键填入，少记一套凭据。</p>
<p>下面按 Flutter 的接入方式说明：字段怎么分组、hint 怎么标、什么时候才真正触发「保存」。</p>
<h2 id="自动填充在-flutter-里怎么工作">自动填充在 Flutter 里怎么工作</h2>
<p>平台侧（iOS 钥匙串 / Android Autofill）认的是一组「当前正在填写的字段」。Flutter 把这组字段抽象成 <strong>autofill context</strong>，核心有三块：</p>
<table>
<thead>
<tr>
<th>API</th>
<th>作用</th>
</tr>
</thead>
<tbody>
<tr>
<td><a href="https://api.flutter.dev/flutter/widgets/AutofillGroup-class.html"><code>AutofillGroup</code></a></td>
<td>把同一次填写相关的输入框绑成一组，一起参与填充与保存</td>
</tr>
<tr>
<td><a href="https://api.flutter.dev/flutter/material/TextField/autofillHints.html"><code>autofillHints</code></a></td>
<td>告诉系统每个框的语义（账号 / 密码 / 新密码）</td>
</tr>
<tr>
<td><a href="https://api.flutter.dev/flutter/services/TextInput/finishAutofillContext.html"><code>TextInput.finishAutofillContext</code></a></td>
<td>结束当前 context；<code>shouldSave: true</code> 时平台会提示保存</td>
</tr>
</tbody>
</table>
<p>同组字段要一起 build；hint 用 <a href="https://api.flutter.dev/flutter/services/AutofillHints-class.html"><code>AutofillHints</code></a> 里的标准值，平台才更容易对上密码管理服务。</p>
<pre class="mermaid-source"><code class="language-mermaid">flowchart LR
  A[账号框 username] --&gt; G[AutofillGroup]
  B[密码框 password / newPassword] --&gt; G
  G --&gt; C[平台 autofill context]
  C --&gt;|成功| D[&quot;finishAutofillContext(shouldSave: true)&quot;]
  C --&gt;|离开页面| E[&quot;onDisposeAction: cancel&quot;]</code></pre>

<p>密码框也可以抽成组件，默认 hint 就是 <code>AutofillHints.password</code>，登录页直接用默认值即可。</p>
<p><code>TextInputAction.next</code> / <code>go</code> 和自动填充无关，但和填充后的键盘路径一致：账号回车跳密码，密码回车提交，少一次点按钮。</p>
<h2 id="只在成功时保存">只在成功时保存</h2>
<p><code>AutofillGroup</code> 默认的 <code>onDisposeAction</code> 是 <a href="https://api.flutter.dev/flutter/widgets/AutofillContextAction.html"><code>AutofillContextAction.commit</code></a>：顶层 Group 销毁时会按「建议保存」结束 context。登录页用户随时可能切验证码登录、返回上一页，这时并不该弹「是否保存密码」。</p>
<p>所以这里显式写成 <code>cancel</code>：销毁时不保存。真正保存放在业务成功回调里：</p>
<figure data-rehype-pretty-code-figure=""><pre tabindex="0" data-language="dart" data-theme="ayu-dark"><code data-language="dart" data-theme="ayu-dark" style="display: grid;"><span data-line=""><span style="color:#39BAE6">Future</span><span style="color:#BFBDB6">&#x3C;</span><span style="color:#FF8F40">void</span><span style="color:#BFBDB6">> </span><span style="color:#FFB454">onLoginSuccess</span><span style="color:#BFBDB6">() </span><span style="color:#FF8F40">async</span><span style="color:#BFBDB6"> {</span></span>
<span data-line=""><span style="color:#39BAE6">  TextInput</span><span style="color:#BFBDB6">.</span><span style="color:#FFB454">finishAutofillContext</span><span style="color:#BFBDB6">(shouldSave</span><span style="color:#F29668">:</span><span style="color:#D2A6FF"> true</span><span style="color:#BFBDB6">)</span><span style="color:#BFBDB6B3">;</span></span>
<span data-line=""><span style="color:#5A6673;font-style:italic">  // toast、跳转首页…</span></span>
<span data-line=""><span style="color:#BFBDB6">}</span></span></code></pre></figure>
<p>对应关系可以记成：</p>
<table>
<thead>
<tr>
<th>时机</th>
<th>行为</th>
</tr>
</thead>
<tbody>
<tr>
<td>登录 / 注册 / 重置成功</td>
<td><code>finishAutofillContext(shouldSave: true)</code></td>
</tr>
<tr>

</table>
<p>验证码登录没有密码字段，不必进这套保存流程；只在密码登录成功分支调用即可。</p>
<h2 id="注册--重置密码补上隐藏账号框">注册 / 重置密码：补上隐藏账号框</h2>
<p>注册、忘记密码的最后一步通常只有「新密码 + 确认密码」。系统保存凭据需要账号和密码成对出现；只有密码框时，保存结果往往不完整。</p>

<h2 id="小结">小结</h2>
<ol>
<li>用 <code>AutofillGroup</code> 把同一次填写的账号、密码绑在一起，并打上标准 <code>AutofillHints</code>。</li>
<li>销毁默认用 <code>cancel</code>，避免中途离开也弹保存；只在登录 / 注册 / 重置成功时 <code>finishAutofillContext(shouldSave: true)</code>。</li>
<li>只有密码的步骤用隐藏账号框补齐凭据对，新密码用 <code>newPassword</code>。</li>
</ol>
